#1: Designing a water Cherenkov detector using Geant 4
This project was completed as part of my undergraduate dissertation and uses the CERN-developed Geant4 Monte Carlo simulation toolkit to model high-energy neutron interactions with detector materials. A virtual detector environment was constructed to study particle transport, interaction processes, and detector response, supporting the optimisation and evaluation of detector designs.

I used Geant4 and PyCrust to model a Cherenkov water detector designed for neutron monitoring in space weather events. The project focused on a lead–water–gadolinium system, where fast neutrons produce cascades that eventually generate Cherenkov light via gamma interactions. I explored how changes in detector geometry affect sensitivity, especially the balance between thermal, evaporation, and high-energy neutron responses.
